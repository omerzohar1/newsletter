יש לכם קובץ אקסל? Copilot יהפוך אותו לדשבורד

בכמה צעדים פשוטים, בלי Power BI ובלי ידע טכני, מקבלים דשבורד אינטראקטיבי עם מדדים, גרפים ומסננים, ישירות מתוך הנתונים שלכם.

ל-Copilot, כלי ה-AI של Microsoft שזמין לכל עובדי הקבוצה, יש יכולת שלא כולם מכירים: הוא יודע לקחת גיליון אקסל ולבנות ממנו דשבורד מעוצב בסגנון Power BI.

הסוד הוא בשיטה: קודם נותנים לסוכן Prompt Coach לכתוב עבורנו הוראות מדויקות שמותאמות לקובץ, ורק אחר כך מבקשים מ-Copilot לבנות את הדשבורד. כך התוצאה מדויקת יותר, וחוסכים הרבה ניסוי וטעייה.

רקע | למה זה שווה לכם

🎯 מנתונים לתמונה ברורה

רואים הכול במבט אחד: במקום לגלול בין עשרות שורות, הסיכומים, המגמות וההשוואות מוצגים בדף אחד.

בלי לבנות לבד: לא צריך נוסחאות, טבלאות ציר או Power BI. מספיק קובץ אקסל מסודר.

שתי שיחות, שני תפקידים: Prompt Coach "קורא" את הקובץ וכותב הוראות מותאמות אישית, ו-Copilot בונה לפיהן דשבורד טוב יותר כבר בניסיון הראשון.

✅ עובדים בראש שקט: Copilot פועל בתוך סביבת Microsoft הארגונית שלנו, כשמחוברים עם המשתמש הארגוני. אפשר לצרף אליו את קבצי העבודה הרגילים.

🛠️ איך עושים את זה

שלב #1

פותחים את אפליקציית Copilot

פותחים במחשב את אפליקציית Copilot. היא אמורה להיות מותקנת אצל כולם, כל עוד המחשב מעודכן.

מוודאים שאתם מחוברים עם המשתמש הארגוני: כתובת המייל של העבודה והסיסמה של המייל.

🔑 אין לכם את האפליקציה, או שאתם לא מחוברים עם המשתמש הארגוני? פנו אלינו בצוות גבאי AI ונעזור לכם בהתקנה ובהתחברות. הפרטים בתחתית הניוזלטר.
שלב #2

מוצאים את הסוכן Prompt Coach

1
בסרגל הצד לוחצים על סוכנים. ייפתח חלון קטן עם רשימת סוכנים, ובתחתיתו לוחצים על הצגת סוכנים נוספים.
2
במסך שנפתח גוללים עד הסוף למטה, לקטגוריה הצגת סוכנים נוספים, ולוחצים על Prompt Coach (האייקון הסגול).
שלב #3

מוסיפים את הסוכן ופותחים אותו

נפתח חלון עם תיאור הסוכן. בפעם הראשונה לוחצים על הוסף, ואחר כך על פתח. תיפתח שיחה חדשה עם Prompt Coach.

💡 מוסיפים רק פעם אחת. מהפעם הבאה Prompt Coach כבר יופיע ברשימת הסוכנים, ולא צריך לחפש אותו שוב.
שלב #4

מצרפים את קובץ האקסל ומדביקים את הפרומפט

בשיחה עם Prompt Coach מצרפים את קובץ האקסל שרוצים להפוך לדשבורד. אחר כך מעתיקים את הפרומפט הבא בדיוק כמו שהוא (אפשר בכפתור "העתקה"), מדביקים בתיבת ההודעה ושולחים:

הפרומפט ל-Prompt Coach
I have attached an Excel sheet. Read every column and the data in it, then write me one detailed prompt that I can give to Copilot to build an interactive dashboard from this sheet. The dashboard should have KPI cards for the key totals, charts that suit this data, and filters for the main categories, styled like a Power BI report page. The prompt you write must tell Copilot to put all the numbers directly in the dashboard, draw everything with plain html, CSS and JavaScript with no external libraries, and give the result as a downloadable .html file. Give me only the prompt, ready to copy.
⛔ לא משנים אף מילה. את הפרומפט אפיין ודייק יהונתן סקורי, אחרי עבודה רבה ומאומצת עד שהגיע לתוצאה הרצויה. תודה יהונתן! כל שינוי, אפילו קטן, עלול לפגוע בתוצאה.
שלב #5

מעתיקים את התשובה ועוברים לשיחה חדשה

1
נותנים ל-Prompt Coach לסיים לעבוד. הוא יחזיר פרומפט חדש וארוך באנגלית, שנכתב במיוחד לעמודות ולנתונים של הקובץ שלכם. מעתיקים את כולו, מההתחלה ועד הסוף.
2
פותחים שיחה חדשה ורגילה ב-Copilot (לא בתוך Prompt Coach).
3
בשיחה החדשה מצרפים שוב את אותו קובץ אקסל, מדביקים את הפרומפט שהעתקתם ושולחים.
⛔ חובה לצרף את הקובץ שוב. השיחה החדשה לא "זוכרת" את מה שהעליתם ל-Prompt Coach. בלי הקובץ אין נתונים לדשבורד.
💡 לא צריך להבין כל מילה בפרומפט שקיבלתם. הוא מיועד ל-Copilot, לא לנו.
שלב #6

מקבלים את הדשבורד ובודקים אותו

Copilot יבנה את הדשבורד ויחזיר אותו כקובץ ‎.html להורדה. מורידים את הקובץ ופותחים אותו בלחיצה כפולה. הוא ייפתח בדפדפן, ואפשר לשחק עם המסננים.

✅ לפני שמשתפים: בודקים שהמספרים המרכזיים תואמים לאקסל (סכומים, ספירות, ממוצעים).
תוצאה | מה מקבלים

📊 מה יש בדשבורד?

🔢

כרטיסי KPI

הסיכומים החשובים (סה"כ, ממוצעים, ספירות) בראש הדף.

📈

גרפים מותאמים

סוגי גרפים שנבחרים לפי הנתונים: עמודות, מגמות, התפלגויות.

🎛️

מסננים

סינון לפי הקטגוריות המרכזיות, למשל פרויקט, חודש או מחלקה.

📁

קובץ אחד עצמאי

קובץ HTML שנפתח בכל דפדפן, בלי התקנות. הנתונים שמורים בתוכו.

⚠️ חשוב לזכור: הדשבורד הוא "צילום מצב". אם הנתונים באקסל משתנים, הוא לא מתעדכן לבד, וצריך להריץ את התהליך מחדש עם הקובץ המעודכן.

שימו לב | טעויות נפוצות

⛔ מה כדאי להימנע ממנו

  • שוכחים לצרף את האקסל בשיחה השנייה. בלי הקובץ, Copilot עלול להמציא נתונים או לבנות דשבורד ריק.
  • ממשיכים באותה שיחה עם Prompt Coach. את הדשבורד בונים בשיחה חדשה ורגילה של Copilot.
  • "משפרים" את הפרומפט באנגלית. מעתיקים אותו בדיוק כמו שהוא, כולל כל הסימנים.
  • קובץ לא מסודר. תאים ממוזגים, כמה שורות כותרת או שורות סיכום באמצע הטבלה מבלבלים את ה-AI.
  • סומכים על המספרים בלי לבדוק. AI יכול לטעות. מצליבים את הנתונים המרכזיים מול האקסל.

✅ צ'קליסט לפני ששולחים

  • ✅ אפליקציית Copilot פתוחה, ואני מחובר עם המשתמש הארגוני
  • ✅ Prompt Coach נוסף לרשימת הסוכנים שלי
  • ✅ קובץ האקסל מסודר: שורת כותרות אחת, בלי תאים ממוזגים
  • ✅ הפרומפט ל-Prompt Coach הועתק מילה במילה
  • ✅ בשיחה החדשה צירפתי שוב את הקובץ
  • ✅ בדקתי שהמספרים בדשבורד תואמים לאקסל
בונוס | טיפים מהירים

💡 עוד כמה דברים קטנים

  • לא אהבתם משהו? ממשיכים באותה שיחה ומבקשים שינוי, למשל: "תחליף את גרף העוגה בגרף עמודות" או "תוסיף מסנן לפי חודש".
  • לא קיבלתם קובץ להורדה? כותבים ל-Copilot: "Give me the result as a downloadable .html file"
  • כמה גיליונות בקובץ? עדיף להשאיר רק את הגיליון הרלוונטי, או לציין באיזה גיליון מדובר.
  • שמרו את הפרומפט שקיבלתם. אם יש לכם קובץ קבוע באותו מבנה (למשל דוח חודשי), אפשר לדלג על Prompt Coach בפעם הבאה.
